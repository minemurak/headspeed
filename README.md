# ヘッドスピード（iPhone 試作版）

三脚にiPhoneを置いて打つだけで、ヘッドスピード・ボール初速・ミート率などを自動で計測する試作アプリです。タップで印をつける操作はありません。

## 測れるもの

| 指標 | 方法 | 合成映像での検証結果 |
|---|---|---|
| ヘッドスピード | インパクト直前4コマのヘッド先端の移動 | 誤差 ±2.5% 以内 |
| ボール初速 | インパクト後のボールを2〜4コマ追跡 | 誤差 ±0.5% 以内 |
| ミート率 | 初速 ÷ ヘッドスピード | ±0.03 以内 |
| 打ち出し角（上下） | ボールの移動方向 | ±0.1° |
| 入射角 | ヘッドの移動方向（スイング半径を仮定して補正） | ±2°（参考値） |
| テンポ | 画面全体の動きから始動・トップを推定 | 実際より1割ほど小さく出る傾向（参考値） |
| 推定キャリー | 初速(m/s)×4 ヤード（ドライバーのみ） | 目安 |

スピン量・フェース角・左右の方向は測れません（弾道測定器が必要）。

検証は `reference/` の合成映像（240fps、シャッター1/1000秒、ノイズ入り、右打ち・左打ち、コマ落ちあり）で行ったもので、実機の映像ではまだ確かめていません。

### 後方から撮る場合（後方モード）

画面左下の「正面／後方」で切り替えます。後方（飛球線の後ろ）からだとボールもヘッドもほぼカメラから遠ざかる向きに動くので、正面とは別の方法で測ります。

| 指標 | 方法 | 合成映像での検証結果 |
|---|---|---|
| ボール初速 | ボールが小さくなっていく速さ（ボールの大きさから距離を出す）と画面上の動きから3次元で計算 | 誤差 ±1.5% 以内 |
| 打ち出し角（上下） | 同上の3次元の向き | ±0.7° |
| ヘッドスピード | インパクト直前約9コマのヘッドの軌跡に円弧を当てはめる（半径・スイング面の傾き・加速を推定） | 誤差 ±2.5% 以内 |
| ミート率 | 初速 ÷ ヘッドスピード | ±0.06 以内 |

ボールは輪郭（丸い縁）で探すので、逆光で周りより暗く写る場合や、ボールの上半分が暗い芝・下半分が明るい通路に重なる場合も検出します（ティーに乗せたままでも可）。ただし逆光ではボールと背景の明るさの差が小さくなるため、合成映像での誤差は初速 ±3.5%、ヘッドスピード ±6% に広がります。

- 入射角は後方モードでは出ません。
- ヘッドスピードは「ヘッドは円弧を描く」「スイング半径はクラブごとの標準値（ドライバー1.6m など）から±15%程度」という仮定に頼っています。合成映像はこの仮定どおりに動くため誤差が小さく出ています。実際のスイング（体の移動、シャフトのしなり、手首のリリース）では正面モードより誤差が大きくなる見込みです（目安 ±5〜10%、実機では未確認）。ボール初速はこの仮定を使わないので、後方モードではボール初速のほうが信頼できます。
- 距離の計算にカメラの画角（iPhoneが報告する値）を使います。画角の誤差がそのまま速度の誤差になります（通常1〜2%）。

## しくみ

1. **撮影**：背面カメラを240fps（非対応機では計測できません）、シャッター上限1/1000秒で動かします。
2. **ボール検出**：画面の点線枠の中で、明るく丸い物体を探します。0.5秒動かなければロック（露出・ピントも固定）。
3. **自動トリガー**：ボールの中心部分の明るさが変わった瞬間（ヘッドが当たった瞬間）を検出。直前約0.8秒と直後0.17秒のコマを保存します。
4. **自動解析**：
   - 物差し：ボールの直径（42.67mm）
   - ヘッド：打つ前の背景との差分から、ボール高さの帯でヘッド先端を検出
   - ボール：背景より明るく丸い塊のうち、最も前にあるものを追跡
5. **結果**：画面に表示し、ヘッドスピードとミート率を読み上げます。履歴に自動保存（クラブ別の平均・CSV共有）。各スイングの swing.json も保存され、履歴の行のボタンからあとで書き出せます（映像 swing.mov は直近10スイング分だけ保存）。右上の共有メニューから全スイングの JSON をまとめて書き出せます。

打球音は使っていません。練習場では隣の打席の音で誤作動するため、映像の変化でトリガーしています。

## iPhoneへの入れ方（Mac不要・TestFlight）

ビルドと署名はGitHub上のMac環境で行います。必要な作業はすべてブラウザとiPhoneでできます。

1. **Apple Developer Program に登録**（有料・年額）。iPhoneの「Apple Developer」アプリから登録できます。
2. **バンドルIDを登録**：developer.apple.com → Certificates, Identifiers & Profiles → Identifiers → ＋ → App IDs → App。Bundle ID に `com.minemurak.headspeed`（Explicit）を入力。
3. **App Store Connect にアプリを作成**：appstoreconnect.apple.com → アプリ → ＋ → 新規App。プラットフォームiOS、名前は任意、バンドルIDは2で登録したもの、SKUは任意（例 headspeed）。
4. **APIキーを作成**：App Store Connect → ユーザとアクセス → 統合 → App Store Connect API → チームキー → ＋。アクセスは **Admin**（署名証明書を自動作成するため）。作成後、AuthKey_XXXX.p8 をダウンロード（1回しかダウンロードできません）。
5. **GitHubにシークレットを登録**：リポジトリ → Settings → Secrets and variables → Actions → New repository secret。
   - `APPLE_TEAM_ID`：developer.apple.com → アカウント → メンバーシップ詳細のチームID（10文字）
   - `ASC_KEY_ID`：4で作ったキーのキーID
   - `ASC_ISSUER_ID`：キー一覧の上に表示される発行者ID
   - `ASC_KEY_P8`：ダウンロードした .p8 ファイルの中身をすべて貼り付け
6. **アップロード**：Actions → testflight → Run workflow。以降は main に変更が入るたびに自動でアップロードされます。
7. **iPhoneに入れる**：App Store Connect → TestFlight → 内部テスト にグループを作って自分を追加。iPhoneに「TestFlight」アプリを入れると、ヘッドスピードが表示されます（処理に10〜30分ほどかかることがあります）。

シークレットが未登録のあいだ、testflight ワークフローは何もせずに終了します。

## Macでビルドする場合

1. Xcode 26 以降と XcodeGen（`brew install xcodegen`）をインストール
2. このフォルダで `xcodegen` を実行し、`HeadSpeed.xcodeproj` を開く
3. Signing & Capabilities で Team を選び、iPhone をつないで実行（シミュレーターにはカメラがないため動きません）

## 撮影のしかた

- 飛球線と直角（正面）、ボールから1〜3mに三脚で固定。練習場で低く置けないときは、正面の斜め上から見下ろしても大丈夫です（40°くらいまで。傾きはiPhoneのセンサーで測って自動で補正します）
- 画面を横向き（ホームボタン側/充電口が右）で置く
- ボールは点線枠の中へ。緑の円が出たら準備完了
- 屋外の明るい場所で。シャッターが1/700秒より遅いと警告が出ます
- ボールの直径が画面上で14ピクセル以上になる距離で（小さいと警告）

後方モードでは：

- 飛球線の真後ろ（ボールと目標を結ぶ線の延長上）、ボールから2.5〜3m、腰の高さ（0.5〜1m）に三脚で固定。左右に50cm程度ずれても大丈夫です
- ボールが画面の下寄り・左右の中央付近（後方モードの点線枠の中）に写るように。ヘッドが上から下りてくる範囲とボールが飛んでいく先が画面に入るようにします
- 打った後、ボールが画面内で小さくなっていくのが見える向き（目標方向）にカメラを向けます
- 後方からだと、構えたときにヘッドがボールの手前に来てボールが隠れます。ボールを置いたら、クラブを離したまま「準備OK」になるのを待ってから構えてください。準備OKの後は、構えてボールが隠れても待機を続け、テークバックでボールが見えてから打った瞬間を拾います
- 枠の中にボールが2つ以上あると（オートティーに残ったボールなど）、打たないほうに丸が付くことがあります。そのときは打つボールを画面でタップすると、そのまわりだけを探すようになります（次のボールも同じ場所に置けばそのまま使えます）。写真の外側（左右の黒い部分）をタップすると自動に戻ります。正面モードでも同じです
- 準備OKの間にスマホに触れたり三脚がぶつかったりして画面全体が動いたときは、スイングとは見なさず結果を出しません（前の結果はそのまま残り、ボールを探し直します）。結果を書き出すときにスマホに触れても、表示中の結果と書き出しファイルは置き換わりません
- 正面モードでも、晴れた日は構えたヘッドの影がボールにかかり、テークバックで影が外れてボールが明るく戻ります。こうしたゆっくりした明るさの変化では反応せず、インパクトのような一瞬の変化だけを拾います
- 正面モードで太陽がボールの向こう側にあると、ボールは手前の一部だけが明るく、残りは日なたの芝と同じくらいの暗さになります。明るい丸として見つからないときは、まわりより明るい部分と、明るい側の輪郭（円弧）からボールを見つけます

## ブラウザ版（手動で印をつける版）

`web/index.html` は、撮影済みのスロー動画を読み込んでタップで印をつけて計測するブラウザ版です。ファイルをブラウザで開くだけで動きます。

## ファイル構成

```
HeadSpeed/
  App/HeadSpeedApp.swift       起動
  Camera/CaptureEngine.swift   240fps撮影、ボール検出、トリガー、解析の呼び出し
  Camera/FrameRing.swift       直近1秒分のコマ（ボール周辺の帯のみ）を保持
  Camera/CameraPreview.swift   プレビュー表示
  Analysis/SwingAnalyzer.swift ヘッド・ボールの検出と速度計算（reference/analyzer.py と同じ処理）
  Analysis/RearAnalyzer.swift  後方モードの解析（reference/analyzer_rear.py と同じ処理）
  Analysis/TempoAnalyzer.swift テンポ推定（reference/tempo.py と同じ処理）
  Analysis/BallFinder.swift    静止したボールの検出
  Views/                       画面（結果カード、履歴）
  Store/                       履歴の保存、読み上げ
reference/
  sim.py       合成スイング映像の生成
  analyzer.py  解析ロジックの参照実装
  tempo.py     テンポ推定の参照実装
  test.py      合成映像での精度テスト（python3 test.py、numpy が必要）
  sim_rear.py / analyzer_rear.py / test_rear.py  後方モードの合成映像・参照実装・精度テスト
  replay.py  アプリで書き出したスイング（swing.mov + swing.json）を参照実装で解析し直す（ffmpeg が必要）
  shake.py / test_shake.py  トリガー時にカメラ自体が動いたかの判定とテスト（fixtures/rear_bumped.jpg は実機でスマホが揺れたときのフレーム）
  ballfinder.py / test_ballfinder.py  静止ボール検出の参照実装（後方モード）とテスト（pillow も必要。fixtures/ は実機の打席で撮った画面）
```

## 既知の制約・未確認の点

- GitHub Actions でコンパイルが通ることは確認済みです（`build` ワークフロー）。
- 実機映像での精度は未検証です。実際の芝・マット・照明で閾値の調整が必要になるかもしれません。
- 端末の向きは「横向き・充電口が右」を前提にしています。プレビューが上下逆に見える場合は `CameraPreview.swift` の回転角を調整してください。
- 入射角はスイング半径をクラブ別に仮定した補正値です。
